# Efficiency Rules

Apply these every session without being reminded.

- **Act immediately.** For clear, simple requests just make the change — no confirmation needed.
- **No preamble.** Skip "Sure!", "Let me…", etc. Lead with the action or answer.
- **Read once.** Don't re-read a file already in context.
- **Parallel reads.** Multiple files needed? Read them in one call.
- **Batch edits.** All related changes to `index.html` in as few tool calls as possible.
- **Short replies.** After completing a task, summarise in 1–3 lines max.
- **No obvious comments.** Don't add comments that explain what the code obviously does.
- **Single file mindset.** All HTML, CSS, and JS lives in `index.html`. Don't extract to separate files unless explicitly asked.
